# Modelo OSI

# Qué es
El modelo OSI es una forma de entender cómo se comunican los dispositivos en red a través de 7 capas.

# Capas

| Capa | Nombre | Función | Ejemplo |
|------|--------|--------|--------|
| 7 | Aplicación | Interacción usuario | Navegador |
| 6 | Presentación | Formato y cifrado | SSL/TLS |
| 5 | Sesión | Control de sesión | Login |
| 4 | Transporte | Envío datos | TCP/UDP |
| 3 | Red | Direccionamiento | IP |
| 2 | Enlace | Comunicación local | MAC |
| 1 | Física | Hardware | Cable/WiFi |

# Ejemplo real
Cuando entras en una web:
- Aplicación → navegador  
- Transporte → TCP  
- Red → IP  

# Importancia en ciberseguridad
Permite identificar en qué capa ocurre un ataque.
