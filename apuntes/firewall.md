# ¿Qué es un Firewall?

Un firewall es un sistema de seguridad que controla el tráfico de red, permitiendo o bloqueando conexiones según un conjunto de reglas definidas.

Actúa como una barrera entre una red interna (segura) y redes externas (como Internet).

# ¿Para qué sirve?

El firewall se utiliza para proteger sistemas y redes frente a accesos no autorizados. Su función principal es filtrar el tráfico de entrada y salida.

# ¿Cómo funciona?

El firewall analiza cada conexión y decide si permitirla o bloquearla en función de reglas como:

- Dirección IP
- Puerto
- Protocolo (TCP, UDP)
- Tipo de tráfico

# Tipos de firewall

# Firewall de red
Protege toda una red, como el router de una casa o empresa.

# Firewall de host
Se instala en un dispositivo concreto (por ejemplo, en un ordenador).

# Uso en ciberseguridad

El firewall es una herramienta clave en defensa (Blue Team). Permite:

- Bloquear conexiones sospechosas
- Limitar accesos a ciertos servicios
- Detectar actividad anómala

Por ejemplo, se puede configurar para bloquear múltiples intentos de conexión desde una misma IP.

# Conclusión

El firewall es una de las primeras líneas de defensa en ciberseguridad. Su correcta configuración es esencial para proteger sistemas y prevenir ataques.
