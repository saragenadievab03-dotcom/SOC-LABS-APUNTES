# Apuntes: Alertas en un SOC

# Qué es una alerta:

En un Security Operations Center (SOC), una alerta es una notificación automática que indica que algo inusual o sospechoso está ocurriendo en la red o en un sistema. Por ejemplo: múltiples intentos fallidos de login, tráfico raro hacia un puerto no habitual o un archivo modificado de manera inesperada.

# Por qué son importantes:

Las alertas permiten a los analistas SOC detectarlas y priorizarlas rápidamente, para investigar si son incidentes reales o falsos positivos.

* Ayudan a reaccionar a tiempo ante ataques
* Permiten documentar patrones de amenazas
* Facilitan el aprendizaje práctico: cuanto más alertas revises, más rápido reconoces riesgos

# Tipos comunes de alertas:

* Login fallido repetido → posible ataque de fuerza bruta
* Escaneo de puertos → posible reconocimiento de red
* Malware detectado por antivirus o EDR
* Cambios no autorizados en archivos críticos

# Mi aprendizaje personal:

Al empezar a practicar labs, me di cuenta de que una alerta no siempre significa un ataque, pero es el primer indicio que un SOC revisa. Aprender a leerlas, filtrarlas y priorizarlas me está enseñando a pensar como un analista de seguridad: no reaccionar a todo, pero no ignorar nada.
