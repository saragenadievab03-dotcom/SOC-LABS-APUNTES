# Tipos de Redes Informáticas


Las redes informáticas permiten la comunicación entre dispositivos y sistemas.

# LAN (Local Area Network)


Red local utilizada en espacios pequeños como:
- casas
- oficinas
- escuelas

Tiene alta velocidad y bajo alcance.


# WAN (Wide Area Network)

Red de gran alcance que conecta diferentes ubicaciones geográficas.

Ejemplo:
- Internet


# MAN (Metropolitan Area Network)

Red que cubre una ciudad o zona metropolitana.


# WLAN (Wireless Local Area Network)

Red local inalámbrica basada en Wi-Fi.


# Importancia en ciberseguridad

Las redes son fundamentales en ciberseguridad porque permiten:
- transmisión de datos
- comunicación entre sistemas
- análisis de tráfico
- monitorización de amenazas
