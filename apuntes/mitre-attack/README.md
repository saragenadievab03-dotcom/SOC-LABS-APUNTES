# MITRE ATT&CK Basics

MITRE ATT&CK es una base de conocimiento utilizada en ciberseguridad para clasificar técnicas utilizadas por atacantes.

Es ampliamente utilizada por:
- SOC
- Blue Team
- Threat Hunters
- Incident Responders


# Objetivo

Ayudar a identificar:
- técnicas de ataque
- comportamiento malicioso
- actividad sospechosa


# Técnicas comunes

# Initial Access
El atacante obtiene acceso inicial.

Ejemplos:
- phishing
- malware
- credenciales robadas


# Execution
Ejecución de comandos o malware en el sistema.

Ejemplos:
- scripts
- PowerShell
- bash


# Persistence
El atacante intenta mantener acceso al sistema.

Ejemplos:
- cron jobs
- servicios maliciosos
- tareas programadas


# Credential Access
Intento de obtener credenciales.

Ejemplos:
- brute force
- keyloggers
- robo de contraseñas


# Command and Control
Comunicación con servidores externos.

Ejemplos:
- conexiones sospechosas
- tráfico HTTP/HTTPS extraño


# Importancia en Blue Team

MITRE ATT&CK ayuda a:
- detectar amenazas
- clasificar ataques
- investigar incidentes
- mejorar alertas SOC
