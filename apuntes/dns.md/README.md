# DNS

# Qué es
Sistema de nombres de dominio que traduce nombres legibles (ej: google.com) a direcciones IP.

# Cómo funciona
1. Usuario escribe dominio.  
2. Se consulta un servidor DNS.  
3. Respuesta con la IP correspondiente.

# Ejemplo
'google.com' → `142.250.190.78`

# Riesgos
- Phishing: manipulación de DNS para redirigir tráfico.  
- DNS spoofing: ataque que falsifica respuestas DNS.
