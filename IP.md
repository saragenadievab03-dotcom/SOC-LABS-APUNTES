# ¿Qué es una dirección IP?

Una dirección IP (Internet Protocol) es un identificador único que se asigna a cada dispositivo conectado a una red. Permite que los dispositivos se comuniquen entre sí enviando y recibiendo información.

## ¿Para qué sirve?

La dirección IP funciona como una “dirección” en la red. Gracias a ella, los datos saben a dónde tienen que ir, igual que una carta necesita una dirección para llegar a su destino.

## Tipos de direcciones IP

### IP pública
Es la dirección que identifica a un dispositivo en Internet. Es visible desde fuera de la red y suele ser asignada por el proveedor de Internet.

### IP privada
Se utiliza dentro de redes locales (por ejemplo, en casa o en una empresa). No es visible en Internet.

Ejemplos comunes de IP privada:
- 192.168.x.x
- 10.x.x.x
- 172.16.x.x

## Uso en ciberseguridad

Las direcciones IP son fundamentales para el análisis de seguridad. Permiten:

- Identificar el origen de una conexión
- Detectar accesos sospechosos
- Analizar ataques como fuerza bruta o escaneos

Por ejemplo, si una misma IP realiza muchos intentos fallidos de login, puede indicar un posible ataque.

## Conclusión

La IP es un elemento básico en redes y ciberseguridad, ya que permite identificar dispositivos y analizar su comportamiento dentro de un sistema.
