# Phishing Analysis 2 (BTLO)

# Plataforma
Blue Team Labs Online

# Objetivo
Analizar un correo sospechoso para identificar si se trata de un ataque de phishing y extraer indicadores de compromiso.

# Escenario
Se proporciona un email relacionado con una campaña reciente de phishing. El objetivo es analizar su contenido y detectar elementos maliciosos.

## Análisis realizado

Durante el análisis del correo se identificaron varios elementos sospechosos:

- Dirección de correo no legítima
- Intento de suplantación de una empresa conocida
- Uso de lenguaje urgente para engañar al usuario
- Posibles enlaces maliciosos

# Metodología

1. Revisión del remitente del correo
2. Análisis del contenido del email
3. Identificación de patrones de phishing
4. Extracción de indicadores sospechosos

# Indicadores de compromiso (IOC)

- Dominio sospechoso
- URL potencialmente maliciosa
- Estructura típica de phishing

# Aprendizajes

- Cómo analizar correos electrónicos sospechosos
- Identificación de técnicas de ingeniería social
- Importancia de validar remitentes y enlaces

# Relación con SOC

Este tipo de análisis es común en un entorno SOC, donde los analistas deben investigar correos sospechosos y determinar si representan una amenaza.

# Conclusión

El análisis permitió identificar correctamente un intento de phishing, aplicando técnicas básicas de análisis utilizadas en Blue Team.
