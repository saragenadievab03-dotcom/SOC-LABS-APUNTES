# Descripción

Laboratorio orientado a la comprensión de conceptos básicos de redes utilizados en entornos de ciberseguridad y pentesting. Durante el desarrollo se trabajó con protocolos de red, direccionamiento IP, puertos, conectividad y comunicación entre dispositivos.



# Temas vistos

- Modelo OSI y TCP/IP
- Direcciones IP
- Puertos y protocolos
- DNS y DHCP
- Routing básico
- Comunicación cliente-servidor
- Reconocimiento de red



# Herramientas utilizadas

- Wireshark
- Nmap
- Ping
- Traceroute
- Netstat
