# Linux Downloader Analysis

# Plataforma
LetsDefend

# Objetivo
Analizar actividad sospechosa relacionada con un downloader en Linux.

# Escenario
Se detectó actividad potencialmente maliciosa en un sistema Linux.

# Análisis
Durante la investigación se identificaron:
- comandos sospechosos
- posible descarga de archivos
- comportamiento anómalo

# Evidencias
- actividad en terminal
- procesos sospechosos
- conexiones realizadas

# Conclusión
El laboratorio permitió practicar análisis básico de incidentes Linux desde una perspectiva Blue Team.

# Aprendizajes
- análisis de actividad sospechosa
