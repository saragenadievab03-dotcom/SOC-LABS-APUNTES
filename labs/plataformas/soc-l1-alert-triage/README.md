# SOC L1 Alert Triage

------------------------------------------------------------
## Objetivo
En este laboratorio quiero practicar cómo analizar alertas dentro de un Security Operations Center (SOC).  
Mi objetivo es aprender a identificar incidentes, priorizarlos y documentar mis hallazgos como lo haría un analista de seguridad.

------------------------------------------------------------
## Contexto
Este lab simula un entorno real de SOC donde se generan alertas de seguridad que debemos revisar y clasificar.  
Voy a trabajar con diferentes tipos de alertas, revisando logs y evaluando la gravedad de cada una, para entender cómo se toman decisiones en tiempo real.

------------------------------------------------------------
## Tasks

### Task 1: Introduction
Aquí se presenta el escenario del laboratorio y se explican los objetivos de las alertas que veremos.

### Task 2: Events and Alerts
Reviso los eventos generados por el sistema y las alertas asociadas.  
Aprendo a diferenciar alertas críticas de las menos importantes y cómo priorizarlas.

### Task 3: Alert Properties
Analizo las propiedades de cada alerta, como origen, tipo y severidad.  
Esto me ayuda a entender qué información es relevante y cómo interpretarla correctamente.

### Task 4: Alert Prioritisation
Aquí priorizo las alertas según el riesgo y la información disponible.  
Aprendo a tomar decisiones rápidas y a documentar correctamente cada paso.

### Task 5: Alert Triage
Aplico acciones concretas sobre las alertas más importantes, como escalarlas o generar reportes.  
Este paso simula el trabajo de un analista de SOC en un entorno real.

### Task 6: Conclusion
En esta sección escribiré mis aprendizajes finales, como la importancia del análisis de alertas, la documentación detallada y la práctica constante con logs.
