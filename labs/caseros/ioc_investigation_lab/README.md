# IOC Investigation Lab

# Objetivo
Realizar una investigación básica de indicadores de compromiso (IOC) desde una perspectiva Blue Team.

# Escenario
Se detectaron posibles IOC relacionados con:
- direcciones IP sospechosas
- dominios maliciosos
- hashes desconocidos

# Actividades realizadas
- análisis de IOC
- búsqueda de patrones
- revisión de conexiones
- generación de hashes

# Herramientas utilizadas
- grep
- cat
- sha1sum
- ss

# Análisis
Los IOC son utilizados para detectar:
- malware
- conexiones maliciosas
- actividad sospechosa

# Conclusión
El laboratorio permitió practicar investigación básica y análisis de IOC en Linux.
