# DNS Sospechoso - Lab Casero

# Objetivo
Simular la detección de dominios sospechosos en logs DNS como haría un SOC.

# Escenario
Se analizan consultas DNS de una red interna para identificar posibles dominios de phishing.

# Pasos realizados
1. Creación de logs simulados con tráfico DNS.
2. Identificación de dominios normales vs sospechosos.
3. Uso de comandos básicos para filtrar información.
4. Análisis manual de patrones (errores tipográficos, palabras clave).

# Ejemplos sospechosos
- gooogle-login.com
- faceb00k-secure.net
- paypaI-verification.com

# Aprendizajes
1 Cómo detectar phishing mediante DNS
2 Importancia de revisar logs en un SOC
3 Identificación de dominios falsos

# Conclusión final
El análisis de logs DNS permite detectar amenazas tempranas como phishing o suplantación de identidad.
