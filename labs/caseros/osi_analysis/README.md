# OSI Analysis Lab

# Objetivo 
Entender las diferentes capas del modelo OSI mediante comandos reales.

# Pruebas realizadas

# Capa 3 (Red)
- Uso de IP y ping

# Capa 4 (Transporte)

# Aprendizajes
- Cada comando corresponde a una capa
- Ayuda a entender dónde ocurren los problemas en red

# Conclusión
